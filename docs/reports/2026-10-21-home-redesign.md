## 승인과 변경

사용자는 다른 개선을 잠시 미루고 홈/로그인/로그아웃/설정 위치와 디자인 개편을 우선 요청했으며, 공개 홈+분석 작업 공간·상단 내비게이션·프로필 메뉴·별도 설정·밝은 남색/파란색 스타일 배치안을 승인했다.

기존 로그인 폼 우선 진입과 고정 사이드바를 공개 홈/상단 메뉴로 바꿨다. 홈은 소개·분석 시작·명시적 예시 보고서·과정 안내로 구성한다. 로그인 전 개인 업로드/이력/설정은 로그인으로 안내한다. 로그인 성공은 새 분석으로, 로그아웃 성공은 홈으로 돌아간다. 계정 설정은 분석 화면 위에서 제거해 독립된 화면으로 옮겼고 탈퇴는 별도 접힘 영역으로 유지했다. 프로필에는 계정 설정/관리자 전용 운영 관리/로그아웃을 배치했다. 모바일은 펼침 메뉴와 프로필 버튼을 사용한다.

기존 API/인증·재인증/동의·삭제/분석/모델/비용 한도는 유지했다. 기존 Vue 내부 상태 전환을 사용하며 새 라우터나 URL deep link를 추가하지 않았다. 공개 홈의 보고서 구성 미리보기는 실제 판정이 아님을 화면에 표시한다.
