# gpt-transcribe 비교와 실제 뉴스 직접 확보

2026-10-21 KST. 사용자는 운영 whisper-1을 유지하면서 gpt-transcribe를 최대$0.20 안에서 비교하도록 승인했고, 사용 가능한 뉴스 자료도 직접 찾도록 요청했다. 운영 모델 교체는 하지 않았다. [실행 JSON](2026-10-21-transcription-model-comparison.json)·[이전 실자료 진단](2026-10-21-real-korean-diagnostics.md)을 함께 따른다.

## 비교 방법

이전 Zeroth-Korean8개/정부 브리핑45초/안전 대담40초를 그대로 재구성했다. 8 WAV와2 MP4 모두 이전 manifest의 SHA256과 일치한다. gpt-transcribe에는 같은 한국어 힌트 목록을 사용하고 날짜·국가·수치·참조 전사를 넣지 않았다. 언어 힌트는 languages=['ko'], 응답은json이다. [OpenAI Docs](https://developers.openai.com/api/docs/guides/speech-to-text)·[요청 명세](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)·[모델/요금](https://developers.openai.com/api/docs/models/gpt-transcribe)을 확인했다. 확인한 요금은분당$0.0045이며 초당75micros로 보수적 여유1초를 더해 호출 전에 예약했다.

기존 whisper 결과를 기준으로 재사용하고 새 모델을 한 번씩 호출했다. 모델 호출의 비결정성과 서로 다른 실행 시점은 한계다. 코퍼스 제공 전사와 출력의 의미 있는 차이를 대조했으며 독립 청취/WER/CER/대표 표본 정확도나 과학적 우월성 점수는 만들지 않는다. 숫자의 한글/아라비아 표기 차이는 오류로 세지 않았다. 영상 속기록은 단어 단위 정렬 정답이 아니다.

gpt-transcribe 응답에는 이번 요청에서 구간 시간이 없었다. 비교 도구는 텍스트만 수집하고 주장 추출/검색/판정/화면에 연결하지 않았다. 임의로0초~전체길이 타임스탬프를 만들지 않았다. JSON의 상속된 provider versions에는 사용하지 않은 운영 timing/claim/LLM 버전도 있으나, scope와 wordTimestampsAvailable=false가 실제 수행 범위를 표시한다. promptMode=none 대조군도 상속된 speechPromptVersion보다 실제 요청 설정을 우선한다.

## 실제 뉴스 직접 조사·확보

### 현대 GTV 기자 리포트

경기도청 방송국GTV/김세은의 [균형발전의 첫걸음 ‘경기북부 미래 비전 포럼’](https://gnews.gg.go.kr/news/news_detail_m.do?number=202412110741593811C048&s_code=C500), 2024-12-11 게시. 기사 자체에 공공누리 제1유형 출처표시가 있고 본문에 자체 제작GTV 영상과 기자 리포트 원고가 함께 있다. 텍스트에 한정한다는 표시는 관찰되지 않았다. 이 항목 표시를 동일 항목의 자체 제작 영상 뉴스에 적용해 출처 표시/60초 발췌·변환/격리 전사에 사용했다. 별도 영상 다운로드 버튼이나 OpenAI 전용 개별 허가가 있었다고 주장하지 않는다.

명령줄 Vimeo 일반 페이지는 로그인 요구, 공식 iframe 수집은401이었다. Aside에서 로그인 없이 실제11초 공개 재생을 확인했고 플레이어가 요청한 공개HLS로 첫60초만 확보했다. 로그인/계정 생성/접근 제한 우회를 하지 않았다. 브라우저 인증정보를 서버에 옮기지 않았다. 만료형 CDN주소/서명값은 보고서·Git에 보존하지 않고 공개 원문 URL·파일 해시를 남긴다. 이번에 새로 연 확인 탭만 닫았다. 방송 뉴스 형태의 지자체 자체 리포트이며 독립 민영/지상파 방송사 대표 표본은 아니다.

### 역사 뉴스 리포트

[대한뉴스 제23호—휴전협정체결과 포로교환](https://commons.wikimedia.org/w/index.php?oldid=1260287052), KTV 아카이브 원출처/Wikimedia Commons mirror. 파일별 설명이 한국·미국 공개 도메인으로 표시한다. 원본39,485,204byte/SHA1 2af8c653df2beaab4c8f852bc2ef154d36c7be1f를 대조했고30~90초를 발췌·H264/AAC640폭으로 변환했다. 단순 웹페이지 글 라이선스를 영상에 전용하지 않았다. 극장 뉴스 기록물로 현대 방송 뉴스와 구분한다. 파일 날짜 제목은1953-07-20, 설명은7월27일이라 메타데이터를 진위 정답으로 취급하지 않았다.

역사 뉴스의 gpt-transcribe 동일 힌트 실행에서 경제활동인구조사·취업자·실업자·실업률·고용률·경제활동인구가 그대로 등장했다. 무힌트 대조에서는 이 문구가 사라졌으나 원래 음성의 많은 단어는 여전히 불명확/잘못된 형태였다. 힌트 혼입과 불확실 전사를 관찰한 것이며 한 번의 대조로 일반 발생률을 계산하지 않는다.

같은 역사 클립을 운영 whisper 파이프라인으로도 검사했다. 실제 길이 약60.01초인데 마지막60~62초의 추가 구간을 반환해 PROVIDER_RESPONSE_INVALID로 거부됐다. 기존0.25초 경계 보정 범위를 늘리지 않았다. 전사 단계에서 중단돼 해당 뉴스의 주장/근거 판정은 미완료다. gpt-transcribe가 텍스트를 반환한 것을 뉴스 진위 검증 성공으로 쓰지 않는다.

KTV 나누리는 자료별 다운로드 조건/로그인, KFN은 항목별 표시 확인이 필요해 무단 수집하지 않았다. 서울시/서산/제천 등의 제한 라이선스와 정책브리핑의 텍스트 한정 안내를 영상 재사용 허가로 간주하지 않았다.

## 검증과 운영 범위

비교 도구는 기존 verify-live-ai의 실제 미디어 검사/FFmpeg/동의/DB 비용 예약·정리 코드를 재사용했다. 격리된 완료 상태의 시험 작업만 생성하고 큐에 넣지 않았다. 별도 비교 누적 한도와 각 호출의 기존 월 한도를 적용하며 실패·미정산 비용 예약을 유지했다. 가격 계산/한도 초과/잘못된 길이 self-test가 통과했다. 모의 공급자 응답을 실제 비교로 쓰지 않았다.

운영 소스1da60d6/whisper-1·gpt-4.1-mini·Brave/건당$0.20·월$20 설정을 변경하지 않았다. 비교 중 일회성 뉴스 시험 한도만$0.10으로 더 낮췄다. 제품/API/DB 스키마 변경이 없어 제품 테스트/배포를 불필요하게 반복하지 않고 문서만 게시한다. 직전 해당 소스의 CI API97/Worker419는 이전 배포 검증이며 이번 실제 비교 결과와 구분한다. 전체 침투·부하/LSP·독립 청취 정답 검증은 수행하지 않았다.

다음은 도메인과 맞지 않는 힌트/음악·무음/문장 앞뒤 잘림을 다루는 설계와 구간 시간 정렬·참조 범위의 독립 검증이다. 새 모델이 일부 용어를 고쳤다는 이유로 운영 모델이나 판정 정책을 자동 교체하지 않는다.

## 최종 현대 뉴스 결과·비용·정리

GTV 첫60초는 원고의9일·아람누리·새라새극장을 gpt-transcribe가 보존했다. whisper는9.1·아랍누리·세라세로 반환했다. 두 전사 모두2024년 제2회 포럼과 공동선언을 담지만 정렬된 청취 정답이 없어 전체 정확도 점수는 계산하지 않는다. 새 모델은 전사 전용 완료/4650micros다.

같은 GTV MP4를 기존 생산 파이프라인에 넣었을 때 전사는 통과했지만 후보5개가 모두 원문 검증에서 탈락했다. 개최 여부/진행 여부/노력 다짐 여부처럼 원문에 없는 metric, 다른 구간의subject 복사 등이 원인이다. PROVIDER_RESPONSE_INVALID/추출 단계 중단·7304micros이며 뉴스의 근거 판정/보고서 완료로 쓰지 않는다. 기존의 모두 무효 실패 방어를 유지했다. GTV와 역사 뉴스2개 모두 실영상으로 검증했으나 일반 의미 판정은 여전히 미완료다.
