# 첫 구현의 결정과 제한

- 기존 격리 클라우드 checkout/work 브랜치 사용: 환경 경로 보존. 비용/제약: 로컬 변경이 같은 브랜치를 공유한다.
- 유료 제공자·가격/예산 미선정으로 production 어댑터는 실패 처리: 무단 비용과 가짜 완료를 막는다. 제약: 실제 음성 AI 분석은 아직 작동하지 않는다.
- multipart는 비공개 파일로 받으며 실제 형식/길이 검사는 Worker에서 외부 호출 전에 수행: 비동기 흐름 유지. 제약: 부적합 파일도 크기 제한 내에서 잠시 비공개 저장 공간을 사용한다.
- 수치 판정은 기간/대상/항목/단위가 일치하는 정형 기록으로 제한하며 소수값 차이는 검토 대상으로 남긴다. 제약: 일반 뉴스 문장에 대한 유보율이 높고 연구 성능은 미검증이다.
- 정정 맥락을 숨긴 잘린 인용을 막기 위해 최초 Validator는 인용뿐 아니라 전체 수집 텍스트가 정형 기록과 일치해야 확정 근거로 허용한다. 제약: 실제 웹 문서는 대부분 유보되며 후속 문맥 검증 연구가 필요하다.
- Docker 이미지의 소스를 비루트 프로세스가 읽을 수 있도록 빌드에서 읽기 권한을 부여했다. 비밀은 이미지로 복사하지 않는다. 제약: 이미지 사용자는 제품 소스 파일을 읽을 수 있다.
- 실제 AI 제공자·예산/운영 접근이 필요한 Task 5 후반/실자료 smoke는 미완료로 남긴다. 테스트 주입과 가상 보고서를 실제 검증으로 보고하지 않는다.
- 정적 검사 지적은 전체 자동 해소로 표시하지 않는다. 인증 없는 loopback 개발용, 경로 정적 분석 미충족과 품질 후보는 09/원시 보고서에 남긴다. 운영 공개 전 별도 검토가 필요하다.

별도 코드 리뷰의 P2 세 건은 재현 테스트로 수정했다. 리뷰에서 추가 minor 항목은 없었다. 정적 도구의 타입/예외/배치 DB/관측 개선 후보는 보고서에 남긴 후속 품질 작업이다.
