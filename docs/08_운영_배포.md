작업 디렉터리: `/workspace/Fact-checking-website`.

```bash
bash devtools/install.sh
source devtools/activate.sh
# 아래는 선택 AI 게이트웨이가 필요한 작업에서 실행
```

## 3. 설정·비밀·네트워크

- MCP는 `.codex/config.toml`에 있다. 현재 경로는 이 클라우드용 절대 경로다.
- 스킬 링크와 캐시가 다른 머신으로 자동 복제된다고 가정하지 않는다. 새 환경에서 설치·발견을 재검증한다.
- 제공자 인증은 사용할 모델을 결정한 뒤 환경 설정에서 추가한다. 값은 Git에 저장하지 않는다.
- 실제 필요한 외부 도메인과 용도를 기록하고 기존 네트워크 허용 정책을 보존한다.
- 프로세스는 환경 복원 후 재시작해야 한다. 정상 서비스가 이미 있으면 시작 도우미가 재사용한다.

### 평가 실행 기록 요구 (TASK-014)

- A=전사/자막 텍스트 LLM, B=A+검색, C=검색/원문 검증/시각/교차검증/규칙 전체. 가능한 한 같은 평가 자료와 주장 목록을 쓴다.
- 목표 90~120개 영상/구간: 사실·허위 수치·자막 불일치·화면 맥락 왜곡·근거 부족을 포함하고 직접 확인한 정답 근거를 주석한다. 확보 수는 별도로 기록한다.
- 개발/평가 분할, 원본 계열 중복 방지, 라벨 기준, K와 분모, 목표치, 모델/검색 조건은 실행 전에 고정한다.
- Claim Recall, Evidence Precision@K, Evidence Validity, Verdict Macro-F1, Cross-modal F1, False Verdict Rate, Abstention Rate와 처리 시간/비용을 기록한다. 오프라인 5종 판정 지표/분모·채점 CLI는 구현됐으며 Claim Recall·근거/시각·시간/비용/실자료 평가는 후속이다.
- 실행 ID·입력/정답 버전·설정/규칙 버전·원시 출력·오류·사용량·환경·실행 명령을 남겨 비교 가능하게 한다. 결과 저장 경로/도구는 프로토콜에서 정한다.
- 기대 개선이 없더라도 실제 결과를 보고한다. 유보율만으로 성능을 주장하지 않는다.

외부 호출 전 파일/시간/프레임/주장/동시성/재시도/비용 상한과 데이터 전송 범위를 정한다. 검색 캐싱·중복 제거는 비용 개선 제안이며 개인정보/출처 최신성·삭제와 함께 검토한다. 프레임 공개 URL은 별도 동의와 공개 가능 여부 확인 없이 만들지 않는다.

## 8. 개발용 Docker 실행 (2026-10-16)

- README의 Docker/로컬 명령이 현재 실행 기준이다. Compose 전체 이미지 빌드와 웹/API/Worker/DB/Redis 시작 및 브라우저 흐름을 확인했다. 웹만 127.0.0.1:8080에 노출한다.
- API/Worker는 UID 1000, 읽기 전용 rootfs와 비공개 미디어 볼륨, Worker CPU/메모리/PID 제한을 사용한다. proxy CA는 빌드 secret/런타임 read-only secret으로 전달하고 이미지에 복사하지 않는다.
- 작업 중지 후 watchdog은 원래 시작 시각 기준 10분 후 실패로 처리한다. 파일/결과 만료 접근 거부 및 30초 주기 정리, 수동 삭제를 제공한다. 컨테이너 로그/재시작/비밀 없는 env 이름은 README 참조.
- 운영 인증·백업/삭제 보증·실제 AI 제공자·AWS 배포/Cloudflare 도메인/Tailscale 관리 접속 검증은 미완료다. 기존 표의 제품 환경 미구성은 초기 이력이며 로컬 개발 환경만 구성됐다.

## 9. 실제 AI 연결 전 준비 상태 (2026-10-16)

- 런타임 조회에서 실행 환경 running/connected 및 네트워크 enforced를 확인했다. 인증 secret/런타임 변수/외부 identity 바인딩은 없다. VPN/개별 외부 서비스 성공을 뜻하지 않는다.
- 비용 예약/정산 호출 경계의 코드와 테스트를 추가했으며 유료 호출은 하지 않았다. 제공자·모델·문서화된 가격표·통화/예산·외부 전송/보관 정책과 환경 설정이 갖춰진 뒤 실제 SDK를 연결한다.
- Python/DB 회귀 테스트와 API 회귀 테스트를 위해 실행 중 Worker를 중지한 뒤 같은 Compose 파일 조합으로 재시작했다. 테스트는 개발 DB 전용이며 자료 삭제가 수반된다.

## 승인된 실제 제공자 연결 후속 (2026-10-16)

승인 프로필을 켜려면 안전한 로컬 .env 또는 런타임 비밀 설정에 FACTLENS_AI_MODE=openai_brave, OPENAI_API_KEY, BRAVE_SEARCH_API_KEY를 설정한다. 키는 채팅/Git에 보내지 않는다. FACTLENS_JOB_BUDGET_MICROS=200000, FACTLENS_MONTH_BUDGET_MICROS=20000000(USD micro)은 승인 상한이며 더 높이면 설정을 거부한다. Compose는 Worker에만 키를 전달한다. 동일한 Compose 파일 조합으로 Worker를 재생성해야 반영된다. 로컬 Python 실행은 .env를 자동 로드하지 않는다.

Nginx에는 기존 웹 CSP/frame-ancestors none이 있으며 이번에 변경하지 않았다. 보안 헤더는 사용자 인증·개별 데이터 소유권을 제공하지 않는다. 조회용 관리자 UI는 아래 절에 추가했다. 사용자별 운영 권한·감사로그·백업 복구·공개 배포는 미구현/미검증으로 유지한다. 현재 서버는 로컬 개발 전용이다.


## 관리자 접근 설정과 사용 (2026-10-19)

API 전용 별도 Secret 이름은 `FACTLENS_ADMIN_TOKEN`이다. 무작위32바이트 이상에서 생성한32~256자 영숫자/`._~-` 토큰을 사용한다. 값은 환경 Secret 관리에서 생성/주입하고 채팅·코드·문서·셸 인자에 복사하지 않는다. 실제 관리자 Secret은 이번에 등록하거나 저장하지 않았다. 기본값은 비활성503이며 사용자가 주입한 뒤 API를 재시작해야 한다. Compose는 API만참조하고 web/Worker에는전달하지않는다. API키와같은값을재사용하지않는다.

## 로컬 관리자 설정 적용 (2026-10-19, 최신)

사용자의 ‘설정해’ 요청으로 무작위32바이트에서 생성한 관리자 토큰을 Git 제외 로컬 `.env`에 저장하고 파일 권한0600을 확인했다. 값은 출력/문서화하지 않았다. 기존 모드/예산 설정은 보존했다. 실제 클라우드 Secret 저장소에는 관리자 토큰을 등록하지 않았다. 현재 연결 도구는 runtime 조회 전용이어서 환경 설정 workflow를 대신 실행할 수 없다. 영구 Secret 등록은 환경 설정 화면에서 별도로 처리해야 한다.

현재 실행 환경 내부의 `http://127.0.0.1:5173/admin`에서 관리 페이지를 제공한다. API는127.0.0.1:3000이며 자체 실행용 프로세스 환경에 로컬 토큰을 주입했다. 웹에는 토큰을 주입하지 않았고 API/web 시작 환경에서 OpenAI/Brave 키는 제외했다. Worker/유료 분석은 시작하지 않았다. 실행/로그 위치는 Git 제외 `.data/admin-api.pid`, `.data/admin-web.pid` 및 같은 이름의 `.log`이며 로그 파일 권한은0600이다. 토큰을 셸 인자나 로그에서 찾지 않는다.

검증: 토큰 없음401, 잘못된 토큰401, 정상 토큰의 admin-overview-v1 조회200, 관리 페이지200, 로컬 security smoke4/4 통과. 외부 공개·포트 전달·배포는 하지 않았다. 이 URL은 실행 환경 내부 주소이며 사용자 컴퓨터의 localhost에서 직접 접근 가능하다는 뜻은 아니다. 세션/환경 재시작 뒤 프로세스가 중단되면 재실행이 필요하고 환경 교체 시 로컬 파일 보존은 보장하지 않는다. 클라우드 Secret으로 이관할 때는 현재 토큰의 교체와 API 재시작을 함께 수행한다.

## 표 구조 증분의 격리 검증 환경 (2026-10-19)

실행 중인 로컬 관리자 데이터와 분리하기 위해 기존 PostgreSQL에 `factlens_table_context_test` DB를 만들고 기존 마이그레이션을 적용했다. Python/API의 TRUNCATE는 이 테스트 DB에서만 수행했다. Redis는15번 DB, 테스트 API/웹은3001/5174 포트와 별도 scratch 미디어 경로를 사용했다. 브라우저 E2E_BASE_URL을5174로 지정하고 테스트 API의 ALLOWED_ORIGINS에 해당 Origin을 명시했다. 기본 Origin 보호를 완화하지 않았다.
