## 1. 현재 상태

제품 화면·컴포넌트·manifest는 apps/web에 구현했다. 단일 워크스페이스 화면에서 업로드/진행/보고서/이력을 전환한다. OmniRoute 대시보드는 외부 개발 도구이며 제품 프런트엔드가 아니다. 원문은 Vue 3 + TypeScript + Vite를 제안한다. Vue/TypeScript/Vite 구성은 타입·빌드와 브라우저로 검증했다. 미완료 UI/운영 범위는 실제 컴포넌트와 최신 기록을 따른다.

## 2. 선택할 구조

`TASK-003`에서 화면 상호작용, 렌더링/검색 노출 요구, 접근성, 팀 운영 조건을 기준으로 프레임워크·언어·스타일·데이터 접근 방식을 비교한다. 선정 근거는 01의 `DEC-002`에 연결한다.

## 5. 검증 기준

기능별 인수 조건에 맞춰 컴포넌트/통합/E2E 중 필요한 수준을 선택한다. 키보드 탐색, 레이블, 오류 안내, 작은 화면, 로딩·빈 값·오류 상태를 확인한다. 임의의 성능 목표나 테스트 통과를 기록하지 않는다.

## TASK-023 원문 수집·발행 정보 화면

근거 카드의 펼침 영역에서 수집 시각·요청/최종 주소·페이지의 발행 주체/발행일/수정일 관측을 확인한다. 상충/무효/누락은 값으로 임의 해소하지 않는다. 동일 인용이 반복되면 첫 offset을 확정 위치로 표시하지 않고 위치 미확정·발견 개수를 표시한다. 관측 정보는 출처 인증/독립성 증명이 아니라는 설명을 제공한다. 비신뢰 관측값은 v-html 없이 문자로 렌더링하고 원문 링크는 기존 HTTP(S) 검사/rel을 유지한다.

## 출처 등록·재인용 검토 화면 (2026-10-19)

근거 카드에 펼침 영역을 추가해 등록 도메인/발행자 표기 대조 상태·가능한 공통 출처 그룹·관계 신호/관련 주소를 표시한다. 실제 출처 독립성은 확인되지 않았다고 명시하며 등록 대조가 사실성/최초 원본 인증이 아님을 설명한다. 관련 주소와 등록명은 문자로만 표시하고 관측 링크를 자동 방문하지 않는다. 원문 trace/검토 정보가 없는 과거 결과는 임의로 생성하지 않는다.


## TASK-027 읽기 전용 관리자 화면 (2026-10-19)

`main.ts`는 정확한 `/admin` 경로에 AdminDashboard.vue를 표시하고 일반 App의 이력 요청을 시작하지 않는다. App에는 운영 관리 링크를 추가했다. 경로 선택은 표시만 결정하며 실제 권한은 서버의 Bearer 인증으로 검사한다. 토큰은 컴포넌트 메모리만 사용하고 금액은 BigInt로 표시한다. 최근 24시간/UTC월의 차이와 실제 청구·잔액 미확인을 화면에 설명한다. 작은 화면에서는 표 영역만 가로 스크롤하며 입력 label·오류 안내·버튼으로 조작한다.

## 계정 화면과 시각 보고서 (2026-10-19)

AccountPanel.vue는 가입/로그인 입력을 제공하고 App.vue가 auth/session 확인 전 비공개 작업 화면을 숨긴다. 세션 쿠키는 서버가 관리하며 웹 저장소에 토큰/비밀번호를 보관하지 않는다. 로그아웃은 폴링 세대와 분석·이력을 초기화한다. 인증 연결 실패 시 다시 연결 화면을 제공한다.

VisualReview.vue는 추출 범위/부분 상태와 타임스탬프별 자막/OCR, 음성과의 불일치 후보/검토를 표시한다. 클릭은 원본 플레이어 시간 이동이며 비공개 프레임 파일 경로를 노출하지 않는다. 외부 문자열은 Vue 텍스트로 렌더링해 HTML을 실행하지 않는다. 주장 집계는 전체 영상 진실 판정과 구분한다.


EvidencePanel은 ‘표 헤더 참조 관측’과 ‘맥락 검토 표기’를 텍스트로 표시한다. 참조 ID·상태는 인용 셀에 명시된 것만 표시하고, 기간/분모/정정/단위 문자열을 실제 주장 적용 의미로 해석하지 않는다. Unicode offset과 API 경계를 확인했고 기존 HTML 주입 비실행/표 맥락 브라우저 회귀에 새 관측 표시를 함께 검증했다.
