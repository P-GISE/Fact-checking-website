# 07. 백엔드 구조

- 문서 상태: 초안 — 서버 기술과 모듈 미결정
- 제품 구현: Express API/Python Worker 기반 및 규칙 검증 구현; 외부 AI 어댑터 미연결
- 관련: [DB](03_데이터베이스_설계.md), [API](04_API_명세.md), [업무 플로우](05_업무_플로우.md), [운영](08_운영_배포.md)

## 기획서 기반 서버·분석 책임 초안

근거: [기획서 원문](../references/FactLens_AI_기획서_원문.md) 5~10절. Node API(Express 또는 NestJS)·Python/FastAPI Worker·Redis/큐·PostgreSQL·파일 저장소를 제안한다. Worker의 실행/큐 소비 방식과 API 노출 필요성은 미정이다.

| ID | 책임 | 연결 |
|---|---|---|
| BE-001 | Node API: 업로드 검증·작업 생성/조회·결과·접근 제어/삭제 | API-001~008 |
| BE-002 | Python 미디어/AI 경로: FFmpeg·STT·프레임·OCR·주장·검색 | FEAT-002~004/006 |
| BE-003 | Evidence Validator: 원문/출처/기간/대상/수치/맥락/독립성 검증 | FEAT-005 |
| BE-004 | Cross-Modal Validator: 동일 시간 구간의 모달과 외부 근거 비교 | FEAT-007 |
| BE-005 | Rule-based Decision Engine: 근거·규칙에 의한 판정/유보 | FEAT-008 |
| BE-006 | Independent Review: 근거 누락·충돌·과도한 확정 판정 재검토 | FEAT-008 |

이 구분은 논리적 책임이며 각 Agent를 별도 서버/자율 루프로 배포하라는 뜻은 아니다. Agent 합의는 증거가 아니며 규칙 엔진이 검증된 근거를 우선한다. 역할별 JSON 스키마·응답 검증·실패 재처리·모델/프롬프트/규칙 버전을 정의한다. 검색/OCR/미디어 텍스트를 시스템 지시로 승격하지 않고, 임의 명령·내부 URL·비밀에 대한 도구 권한을 제한한다.

OpenAI 전사/언어/시각 모델, Google Fact Check Tools API·Vision Web Detection 등은 후보이며 인증·쿼터·비용·실제 성능은 미검증이다. Fact Check Tools는 기존 팩트체크 검색이며 모든 주장의 참/거짓을 반환하지 않는다. Vision의 이미지 일치는 촬영일·최초 원본 증명이 아니다.

## 1. 현재 상태

제품 서버·작업 큐·manifest는 apps/api, apps/worker와 compose.yaml에 구현했다. `devtools/start-services.py`는 개발 게이트웨이 시작 도우미이며 제품 서버가 아니다.

## 2. 구조 선택 항목

`TASK-003`에서 제품 서버가 필요한지, 배포 단위와 런타임, 동기/비동기 처리, 외부 의존성을 결정한다. 원문은 Node API와 Python Worker 분리를 제안한다. 필요한 만큼의 모듈만 도입한다. 선택하지 않은 프레임워크나 계층을 확정 구조로 표기하지 않는다.

## 3. 모듈 목록 양식

| ID | 모듈 | 단일 책임 | 입력/출력 | 의존 모듈 | 연계 계약 | 실제 파일 |
|---|---|---|---|---|---|---|
| BE-NNN (양식) | 업무 기준 이름 | 처리할 일/경계 | 타입·오류 | 의존 방향 | FEAT-/API-/DB- | 구현 후 연결 |

요청 처리, 업무 규칙, 데이터 접근, 외부 연동의 책임과 트랜잭션 경계를 설명한다. 폴더 구조는 채택한 런타임과 실제 코드에 맞춰 기록한다.

## 4. 처리 경계

- 입력 검증·인증·자원 단위 인가의 실행 위치.
- 업무 상태 전이와 트랜잭션/동시성 제어.
- DB 오류와 API 오류의 매핑, 예상 못 한 실패의 로깅.
- 외부 연동의 타임아웃·재시도·중복 방지·호출 제한.
- 민감정보를 남기지 않는 추적 ID와 관측 지점.
- 백그라운드 작업이 필요하면 실행 보장·취소·재처리·실패 보관 정책.

외부 AI를 채택한다면 입력 데이터 전송 범위, 출력 검증, 프롬프트 주입 대응, 근거 추적과 비용 상한을 09와 함께 설계한다. 개발 도구 설치만으로 AI 제공자 채택을 결정하지 않는다.

## 5. 검증과 완료 기준

모듈별 단위 검증, 실제 DB/외부 연동 경계의 통합 검증, API 계약 검증을 필요한 범위에서 선택한다. 실패 시 부분 반영·중복 실행·권한 우회가 생기지 않는지 확인한다. 실행 명령과 결과는 10에 연결한다.

다음: [TASK-003 → TASK-005](99_해야할일..md). 모듈 책임·계약·실제 경로·오류 처리가 연결되면 설계와 구현 상태를 각각 갱신한다.

## 6. 기획서 모듈별 입출력 책임

근거: [원문](../references/FactLens_AI_기획서_원문.md) 05~07·09.1·10절. 아래 역할은 논리적 모듈이며 개별 서버/자율 루프 수를 확정하지 않는다.

| 역할 | 입력 → 출력 | 소유 책임/경계 |
|---|---|---|
| 미디어 전처리 (BE-002) | 검증된 파일 → 음성·프레임·전사·OCR·시간축 | FFmpeg 분리, OpenCV 프레임, 원본 자막 우선, PaddleOCR 후보 |
| Claim/Audio (BE-002) | 전사/자막 → 원자적 주장·속성·제외 이유 | 숫자/기간/개체·원문 구간을 유지 |
| Retrieval (BE-002) | 주장/시간/대상 → 후보 근거/질의/원문 | 공식 자료·기존 팩트체크·독립 보도·영상 출처 검색 |
| Evidence Validator (BE-003) | 후보+주장 → 존재/발행 주체/인용/날짜/대상/수치/맥락/독립성 검사 | URL 접근과 실제 근거 적합성을 구분 |
| Visual (BE-002) | 프레임/자막 → OCR/시각 속성/일치 자료 후보 | 게시 맥락 확인, 촬영일/최초 원본 추정의 한계 기록 |
| Cross-Modal (BE-004) | 시간 정렬된 모달/검증 근거 → 내부/외부 비교 | 비교 종류·불일치 구간·불확실성 |
| Independent Review (BE-006) | 주장/근거/검사·판정 후보 → 누락/모순/과도한 확정 지적 | 합의가 아닌 근거 충족 여부 확인 |
| Decision Engine (BE-005) | 검증 결과·재검토 결과·규칙 → 최종 판정/유보 | 의미 비교와 프로그램 검사를 병행, 02 규칙 A~E와 버전 연결 |

### 역할 간 스키마 작성 요구

각 출력은 정의된 JSON 스키마로 검증한다. 주장/근거/프레임의 참조 식별자, 출처/시간 구간, 검사 상태·실패 이유, 판정과 불확실성, 모델/프롬프트/규칙 버전의 전달 책임을 계약에 명시한다. 필드명·타입·필수 여부와 역할별 재시도 정책은 TASK-004/013/015에서 확정한다. 잘못된 JSON이나 누락 참조를 정상 판정으로 사용하지 않는다.

제공자 후보는 전사/언어/시각의 OpenAI, 기존 검증 검색의 Google Fact Check Tools, 이미지 일치 탐색의 Vision Web Detection이다. 제공자 교체가 가능하도록 경계를 분리하며 모델·키·쿼터·비용·라이브러리 호환성을 실제 검증하기 전 채택 완료로 기록하지 않는다.

## 7. 실제 모듈과 제한 (2026-10-16)

- apps/api/src: app.ts HTTP/업로드/조회/삭제, cleanup.ts 파일 정리, db.ts 마이그레이션, server.ts Redis 연결/주기 정리.
- apps/worker/factlens: media.py 실제 ffprobe/ffmpeg 제한 실행, queue.py DB 실행 소유권/버전, main.py 단일 소비자/600초 자식 프로세스 제한, pipeline.py 단계 조합, retrieval.py 공개 IPv4 pin/원문 제한 수집, validator.py 정형 수치/인용 검사, decision.py 판정, budget.py 지출 예약.
- Providers는 의도적으로 비활성화돼 있다. 실제 전사·검색·구조화 추출과 가격 기반 예산 예약을 결합하는 외부 SDK 연결은 아직 없다. BE-004/006의 시각/독립 검토는 후속이다.
- 수집은 inherited proxy/CA를 유지하며 검증된 public IPv4로 전송하고 원래 Host/SNI를 보존한다. 호스트 정책이 literal IP를 허용하지 않으면 접근 실패이며 우회하지 않는다. 외부 실제 수집 연결은 미검증이다.
