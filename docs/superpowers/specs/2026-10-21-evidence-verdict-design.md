# 실AI 검증과 근거·판정 보완 설계

사용자 요청: 남은 여섯 분야 중 실AI 전 과정과 근거·판정 기능에 집중한다. 연구 평가·추가 보안 감사·UX·운영 훈련은 이번 범위에 추가하지 않는다. 2026-10-21 사용자는 아래 제한된 문장·표 검증과 종합 보고서 범위를 승인했다. 이 문서는 구현 전 검토 대상이며 구현 완료 기록이 아니다.

## 현재 확인한 상태

- work/d27ca3a, 작업 트리 깨끗함. 실제 운영 배포 소스는3a0cd28.
- 로컬 프로세스와 운영 Worker의 OpenAI/Brave 키가 모두 미설정이다. 운영 AI 모드는 disabled다. 값은 출력하지 않고 존재 여부만 확인했다.
- 과거 합성 한국어 연결 검증은 STT429에서 중단됐다. 현재 키 부재와 과거 계정 오류를 구분한다.

- 자막/OCR 관측과 시간 중첩 수치 비교, 주장별 개수 요약은 있다. 일반 의미 검증·핵심 주장 선정·근거 강도는 아직 없다.

## 1. 실제 AI 전 과정

기존 whisper-1 / gpt-4.1-mini / Brave와 건당200000·월20000000 USD micros 상한을 유지한다. 비밀값은 서버의 기존0600 .env.production에 사용자가 입력한다. 공개 Worker를 먼저 상시 활성화하지 않고 별도 실행의 실제 호출을 검증한다. 실행 중 설정은 DB 예산 예약·정산을 반드시 통과하며 자동 재시도하지 않는다.

직접 작성한 짧은 한국어 합성 미디어를 사용한다. 전사→원자적 주장→Brave 검색→실제 원문 수집/직접 인용→Validator→보고서→비용 기록→시험 자료 삭제를 각각 기록한다. 판정 유보가 적절하면 파이프라인 완주로 인정하되 지지/반박 성공으로 표현하지 않는다. 실패 단계·허용 오류 코드·실제/미확인 비용을 남기며 키·원시 제공자 오류는 기록하지 않는다.

성공 후 공개 활성화는 실제 키·예산·처리 상태를 확인한 뒤 적용한다. 계정429/권한 오류가 남으면 원인을 분리하고 독립적인 판정 구현을 계속한다.

## 2. 출처와 문장·표 의미 검증

첫 지원 범위는 검토한 한 발행기관·한 통계 정의의 연도별 한국 고용률/실업률/인구 중 실제 원문이 확보된 항목이다. 정확한 기관·호스트·공식 정의·공표 원문은 공식 자료를 확인해 정책에 등록한다. 기관 이름만으로 원문 신원이나 사실성을 인증하지 않는다. 검토 근거가 없는 기관은 지원 밖이다.

기존 sourceTrace/tableContext의 관측 계약을 바꾸지 않고 별도 버전의 의미 검사 결과를 추가한다. 결과는 판정 관계, 검사별 통과/실패/미확인, 원문 위치, 정책/규칙 버전을 포함한다. LLM 추출은 후보 생성에만 사용하고 최종 확정은 서버의 검증 조건으로 결정한다.

- 문단: 직접 인용의 유일한 위치, 관련 문단과 전체 문서, 발행/수정 정보, 부정·인용·예측·조건·정정, 기간/대상/항목/단위/분모를 함께 확인한다.
- 표: 같은 표의 명시적 행·열 헤더로 연결된 단일 값과 제목·단위·관련 주석을 확인한다. 병합/중첩 표, 모호한 헤더·각주, 잘린 문서, 다중 기간의 모호한 연결은 유보한다.
- 지지/반박: 같은 통계 정의·기간·대상·단위·분모에서 직접 비교가 가능한 경우만 허용한다. 값 불일치 전에 비교 조건 일치를 확인한다. 단위/기간 불일치는 반박이 아니다.
- 원출처/재인용: 검토된 원출처 연결과 실제 확인하지 못한 관계 후보를 구분한다. 같은 원출처의 복제는 별도 독립 근거로 세지 않는다. 그룹이 없다는 이유로 독립성을 확정하지 않는다.
- 기존 legacy 결과와 기존 정형 수치 규칙은 보존한다. 새 판정은 새 버전으로만 생성한다.

## 3. 모달과 종합 보고서

음성·자막·OCR 기록의 시간/내용 비교와 외부 근거 판정을 별도로 표시한다. 숫자 일치만으로 일반 의미 일치나 영상 전체 사실성을 선언하지 않는다. 모호한 OCR·표본 누락·일반 영상 의미는 명시적으로 검토 필요다.

선택된 주장별 지지/반박/부족/충돌 및 처리 범위를 보고서에 보여 준다. 핵심 주장은 원문 구간과 선정 근거를 보존하며, 검증하지 않은 전체 영상에 결과를 확대하지 않는다. 반박과 확인이 섞였거나 핵심 정보가 미검증이면 해당 상태를 유지한다. 근거 강도는 직접성·비교 조건·확인한 출처 관계의 상태로 설명하고 진실 확률로 표시하지 않는다.

## 인수 조건

1. 실제 AI 한 건의 단계·원문 인용·보고서·비용·삭제 증거가 있거나 외부 차단이 구체적으로 기록된다. 키 등록만 성공으로 표시하지 않는다.
2. 검토한 실제 원문에서 지원 문장/단순 표의 지지·반박 사례를 검증하고 원문 위치와 비교 조건을 추적한다.
3. 부정·정정·조건·다른 기간/단위/분모·중복 인용·위조 호스트/발행자·잘림·재인용 중복·접근 실패에서 잘못된 확정을 거부한다.
4. 외부 판정과 내부 모달 불일치, 근거 부족과 처리 오류를 분리한다. 새 결과와 legacy 결과가 API/화면에서 모두 읽힌다.
5. 변경에 맞는 회귀·타입/빌드·독립 코드 검토와 실제 보고서 확인 후 work에 게시하고 자동 배포 결과를 확인한다.
