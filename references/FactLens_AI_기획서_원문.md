# 졸업프로젝트 상세 기획서

# FactLens AI
## 멀티모달 인공지능 기반 영상 허위정보 탐지 및 근거 교차검증 플랫폼

**작성 기준:** 2026년 10월

**프로젝트 유형:** AI 기반 웹 서비스 / 멀티모달 분석 / AI Agent / 근거 기반 사실 검증

## 01. 프로젝트 개요

### 1.1 프로젝트명

- 한글명: AI 기반 영상 허위정보 탐지 및 교차검증 시스템
- 영문명: FactLens AI
- 부제: Evidence-Based Multimodal Fact-Checking Platform

### 1.2 프로젝트 정의

FactLens AI는 사용자가 뉴스 영상, SNS 동영상 또는 관련 URL을 입력하면 영상의 음성, 자막, 시각적 정보를 분리하여 분석하고, 외부의 신뢰 가능한 근거 자료와 비교함으로써 콘텐츠에 포함된 허위정보와 맥락 왜곡 가능성을 검증하는 AI 기반 웹 서비스이다.

기존의 단순 LLM 질의응답 방식과 달리 하나의 AI가 콘텐츠 전체를 직관적으로 평가하지 않는다.

음성 분석, 시각 분석, 근거 검색, 근거 검증, 교차검증, 판정 과정을 독립된 모듈로 구성하고 각 분석 결과의 근거를 추적할 수 있도록 설계한다.

최종적으로 사용자는 콘텐츠에 포함된 개별 주장의 사실 여부뿐 아니라, 어느 구간에 문제가 있으며 어떤 근거로 판단했는지 확인할 수 있다.

### 1.3 핵심 기능 요약

| 구분 | 핵심 기능 |
|---|---|
| 입력 | 영상 파일 또는 지원 가능한 URL 입력 |
| 음성 처리 | MP3/WAV 추출 및 STT 변환 |
| 영상 처리 | MP4 프레임 추출, OCR, 시각 정보 분석 |
| 주장 분석 | 발언·자막에서 검증 가능한 주장 추출 |
| 외부 검증 | 공식 통계, 기관 발표, 언론 및 팩트체크 자료 탐색 |
| 근거 검증 | URL, 원문, 날짜, 출처, 독립성 검증 |
| 교차검증 | 음성·자막·화면·외부 근거 상호 비교 |
| 결과 | 주장별 판정, 근거 URL, 분석 타임라인, 최종 보고서 |

### 1.4 주요 이용 대상

- 일반 뉴스 및 SNS 이용자
- 영상 기반 정보를 검증하려는 대학생 및 연구자
- 언론 및 팩트체크 관련 종사자
- 미디어 리터러시 교육 기관

## 02. 프로젝트 추진 배경 및 필요성

### 2.1 문제 정의

온라인 플랫폼에서는 뉴스 영상, 숏폼 콘텐츠, SNS 게시물을 통해 다양한 정보가 빠르게 유통된다.

그러나 허위정보는 단순히 완전히 조작된 뉴스에만 존재하지 않는다.

다음과 같은 방식으로도 잘못된 정보를 전달할 수 있다.

1. 사실과 다른 수치나 사건을 발언하는 경우
2. 실제 사건에 잘못된 자막을 덧붙이는 경우
3. 과거 영상을 최근 사건처럼 게시하는 경우
4. 다른 국가의 사건 영상을 국내 사건으로 소개하는 경우
5. 사실인 발언과 관련 없는 화면을 결합하여 오해를 유발하는 경우
6. 일부 정보만 선택적으로 제시하여 전체적인 의미를 왜곡하는 경우

특히 영상 콘텐츠는 음성, 자막, 이미지가 동시에 전달되므로 텍스트만 분석하는 방식으로는 이러한 문제를 충분히 파악하기 어렵다.

### 2.2 기존 방식의 한계

| 기존 방식 | 한계 |
|---|---|
| 일반 LLM 질문 | 검색 없이 판단하면 환각 및 잘못된 추론 가능 |
| 텍스트 기반 팩트체크 | 영상 장면의 출처와 맥락을 검증하기 어려움 |
| 이미지 역검색 | 해당 이미지와 연결된 발언의 사실 여부를 직접 검증하지 않음 |
| 단일 AI 판별기 | 판정 근거와 검증 과정을 추적하기 어려움 |
| 사람의 수동 검증 | 개별 프레임 검색과 근거 조사에 많은 작업 필요 |

### 2.3 해결 방향

본 프로젝트에서는 다음 세 가지를 독립적으로 검증한다.

**첫째, 발언의 사실성**

음성으로 전달한 내용이 실제 사건, 통계 또는 공식 자료와 일치하는지 판단한다.

**둘째, 영상의 맥락적 정확성**

자막과 영상 속 장면이 해당 사건의 날짜, 장소, 상황과 일치하는지 분석한다.

**셋째, AI 판단의 근거 타당성**

AI가 검색한 자료가 실제로 존재하고, 해당 주장에 대한 직접적인 근거인지 추가적으로 확인한다.

## 03. 개발 목표 및 연구 가설

### 3.1 최종 개발 목표

사용자가 하나의 영상 또는 링크만 제공해도 AI가 검증 가능한 주장을 자동으로 추출하고, 여러 종류의 근거를 수집·분석하여 콘텐츠의 신뢰성을 설명하는 웹 기반 검증 플랫폼을 구현한다.

### 3.2 세부 목표

- 영상 음성·시각 정보의 자동 분리 및 분석
- 시간대별 사실 주장 자동 추출
- 근거 검색과 원문 검증 자동화
- 음성·자막·영상 사이의 불일치 탐지
- 판단 근거를 기록하는 AI Agent 구조 구현
- 검증 불가능한 정보에 대한 판정 유보 기능
- 실험 데이터에 기반한 성능 비교 및 검증

### 3.3 핵심 연구 질문

**RQ1.** LLM의 단독 판단보다 외부 근거를 활용한 사실 검증 방식이 더 정확한 판단을 제공하는가?

**RQ2.** 음성·자막·시각 정보를 함께 검증하면 텍스트 기반 검증에서 놓치는 맥락 왜곡을 탐지할 수 있는가?

**RQ3.** 검색한 근거의 출처와 원문을 추가로 검증하면 잘못된 확정 판정과 근거 환각을 줄일 수 있는가?

### 3.4 연구 가설

- H1: 외부 근거 검색을 활용한 시스템이 LLM 단독 판정보다 높은 사실 검증 성능을 보일 것이다.
- H2: 멀티모달 교차검증이 영상 맥락 왜곡의 탐지 성능을 향상시킬 것이다.
- H3: 근거 검증 엔진을 추가하면 유효하지 않은 인용 및 잘못된 확정 판정이 감소할 것이다.

위 가설은 현재 확인된 연구 결과가 아니라 본 프로젝트에서 실험으로 검증할 가설이다.

## 04. 서비스 이용 방식

### 4.1 사용자 이용 시나리오

**STEP 1. 분석 대상 입력**

사용자는 뉴스 영상, SNS 동영상, 지원되는 영상 URL 또는 MP4 파일을 입력한다.

**STEP 2. 미디어 데이터 분리**

입력된 영상에서 음성 데이터를 MP3 또는 WAV로 추출하고, MP4의 프레임 및 자막을 별도로 분석한다.

**STEP 3. AI 자동 분석**

음성 발언과 자막을 분석하여 사실 검증이 필요한 주장을 추출한다.

**STEP 4. 외부 정보 검색**

각 주장과 관련된 공식 발표, 통계, 기존 팩트체크 및 기타 검증 가능한 자료를 검색한다.

**STEP 5. 교차검증**

음성·자막·영상 및 외부 자료 사이에 모순이 존재하는지 검사한다.

**STEP 6. 결과 확인**

사용자는 최종 보고서에서 주장별 판정과 해당 영상 구간, 검증 근거 및 한계를 확인한다.

### 4.2 입력 지원 범위

| 입력 형태 | 처리 방식 | 구현 우선순위 |
|---|---|---|
| MP4 직접 업로드 | 원본 파일 분석 | 필수 |
| MP3/WAV 파일 | 음성 발언 분석 | 필수 |
| 지원되는 영상 URL | 접근 및 사용이 허용된 영상에 한하여 분석 | 확장 |
| 일반 뉴스 기사 URL | 텍스트와 접근 가능한 첨부 미디어 분석 | 확장 |
| YouTube 등의 플랫폼 URL | 공식 API와 플랫폼 정책을 확인하여 지원 | 확장 |

초기 MVP는 직접 업로드한 1~3분 길이의 한국어 뉴스형 영상을 중심으로 구성한다.

URL 분석의 경우 해당 플랫폼의 접근 정책, 저작권 및 이용약관을 우선 적용한다.

## 06. 핵심 기능 상세 설계

### 6.1 미디어 전처리 모듈

**기능 목적**

입력된 영상에서 음성과 시각적 정보를 독립적으로 분석할 수 있도록 데이터를 가공한다.

**음성 처리**

- FFmpeg를 이용한 음성 트랙 추출
- 분석용 MP3/WAV 변환
- 구간 단위 음성 분할
- Speech-to-Text 변환
- 발언 시작·종료 시각 기록

**영상 처리**

- 원본 MP4 보존
- 필요시 음성이 제거된 영상 파일 생성
- 장면 전환 또는 시간 간격에 따른 프레임 추출
- 영상 내 자막과 날짜·숫자·지명 추출
- 원본 자막 트랙이 존재하면 직접 활용
- 영상 프레임과 자막을 타임스탬프에 연결

**주요 기술**

FFmpeg, OpenAI Audio Transcription API, OpenCV, PaddleOCR

**출력 데이터**

- 음성 전사 텍스트
- 발언 타임스탬프
- 영상 프레임
- OCR 추출 결과
- 영상 메타데이터

### 6.2 주장 추출 모듈: Claim Extraction Agent

**기능 목적**

모든 발언이 아니라 실제 사실 여부를 검증할 수 있는 주장만 선별한다.

예시 발언:

"지난해 A시의 인구가 50% 증가했으며, 이는 전국에서 가장 높은 증가율입니다."

AI는 이를 다음과 같이 분해한다.

| 주장 ID | 원자적 주장 |
|---|---|
| C1 | 지난해 A시의 인구가 증가했다 |
| C2 | A시의 인구 증가율은 50%이다 |
| C3 | A시의 인구 증가율은 전국에서 가장 높다 |

원자적 주장(Atomic Claim)이란 다른 주장과 독립적으로 검증할 수 있는 최소 단위의 사실 주장이다.

각 주장에는 다음 속성을 부여한다.

- 주장 원문 및 정규화 문장
- 영상 시작·종료 시각
- 관련 날짜와 기준 연도
- 지역, 대상, 기관, 인물
- 숫자 및 단위
- 주장의 출처: 음성 또는 자막
- 검증 대상 여부와 판단 이유

단순 감상, 의견, 농담, 예측 등 객관적 근거로 참·거짓을 확정하기 어려운 문장은 별도 유형으로 분류한다.

### 6.3 외부 근거 검색 모듈: Evidence Retrieval Agent

**기능 목적**

검증 대상 주장마다 관련 자료를 자동으로 수집한다.

**검색 대상**

| 정보 유형 | 우선 검토할 출처 |
|---|---|
| 재난·기상 | 기상청 및 관련 공식 관측 자료 |
| 인구·경제 통계 | KOSIS 등 공식 통계 |
| 법률·제도 | 국가법령정보센터 및 담당 기관 |
| 정부 발표 | 해당 기관 공식 발표문 |
| 기존 허위정보 검증 | Google Fact Check Tools API |
| 일반 사회 사건 | 직접 자료, 독립적 보도 및 관련 기록 |
| 영상 출처 | 이미지 일치 검색, 기존 공개 영상 및 최초 게시 정보 |

**검색 절차**

1. 주장에 포함된 주요 키워드를 추출한다.
2. 시간·지역·대상 조건을 포함한 검색 질의를 생성한다.
3. 관련성이 높은 자료를 수집한다.
4. 원문 내용과 출처 정보를 저장한다.
5. 검색 결과를 Evidence Validator에 전달한다.

**주의 사항**

Google Fact Check Tools API는 기존에 검증된 주장을 탐색하기 위한 서비스다. 모든 정보에 대해 즉시 사실 여부를 반환하는 기능은 아니다.

검색 결과가 없거나 접근 가능한 근거가 없으면 자동으로 거짓으로 판정하지 않는다.

### 6.4 근거 검증 모듈: Evidence Validator

**기능 목적**

AI가 수집한 자료가 실제로 신뢰할 수 있는 판단 근거인지 확인한다.

본 프로젝트의 핵심 기술 중 하나다.

**검증 항목**

| 검증 요소 | 확인 내용 |
|---|---|
| 출처 존재성 | URL에 정상적으로 접근할 수 있는가 |
| 발행 주체 | 주장한 기관이 실제로 제공한 문서인가 |
| 원문 일치성 | 인용한 내용이 원문에 실제 존재하는가 |
| 날짜 적합성 | 사건 시각과 발표·기록 날짜가 일치하는가 |
| 대상 적합성 | 사건, 장소, 인물, 기관이 같은가 |
| 수치 적합성 | 값, 단위, 분모, 비교 기간이 일치하는가 |
| 맥락 적합성 | 발언의 의미와 근거의 의미가 일치하는가 |
| 독립성 | 다른 자료를 단순 재인용한 것은 아닌가 |

**예시**

주장: "A시의 인구 증가율은 50%다."

근거 자료: "A시 인구는 전년 대비 5% 증가했다."

검증 과정:

- 지역 일치: 통과
- 기간 일치: 통과
- 통계 항목 일치: 통과
- 수치 일치: 실패

**결론: 해당 근거는 50% 증가 주장을 반박한다.**

단순히 같은 지역과 관련된 문서를 발견한 것만으로는 검증이 완료되지 않는다.

또한 공식 기관이 발표했다는 사실과 그 발표 내용이 객관적으로 사실이라는 점도 구분한다. 근거의 권위뿐 아니라 자료의 직접성, 조사 방법, 최신성, 모순 여부를 함께 살펴본다.

### 6.5 주장과 근거의 관계 판정

검증을 통과한 증거에 대해서는 LLM 기반 의미 비교와 프로그램 기반 비교를 병행한다.

**AI 의미 관계 분류**

- `SUPPORTED`: 근거가 주장을 지지함
- `REFUTED`: 근거가 주장을 반박함
- `INSUFFICIENT`: 근거만으로 판단할 수 없음

**프로그램 기반 검사**

- 숫자 및 단위 비교
- 날짜 및 시각 비교
- 기관·지역명 비교
- 부정 표현 및 수치 범위 검사
- 원문 인용 구간 존재 여부 확인

AI가 SUPPORTED라고 판정했더라도 숫자나 날짜가 다르면 다시 검사하도록 한다.

근거의 인용문은 가능하면 원문 문서의 위치 및 구간 정보와 함께 보존한다.

### 6.6 영상 분석 모듈: Visual Analysis Agent

**기능 목적**

화면 자체의 맥락을 분석하여 뉴스에서 설명하는 사건과 일치하는지 확인한다.

**분석 대상**

- 자막
- 영상에 표시된 수치 및 날짜
- 장소를 나타내는 간판·표지판
- 장면 속 사물과 환경
- 화면에 나타나는 주요 사건 및 행동
- 과거 영상 또는 이미지와의 유사성

**원본 추적 방식**

1. 주요 프레임을 선택한다.
2. 이미지 특징 및 유사도를 분석한다.
3. 웹에 공개된 일치·유사 이미지 자료를 탐색한다.
4. 검색 결과의 게시일과 문맥을 확인한다.
5. 서로 동일한 원본에서 파생된 자료인지 비교한다.
6. 원본 영상의 시점과 뉴스가 주장한 시점을 대조한다.

활용 가능한 도구에는 Google Cloud Vision Web Detection 등이 있다.

단, 일치 이미지가 발견되더라도 그것이 최초 촬영본이라는 뜻은 아니다. 게시일과 실제 촬영일 역시 구분해야 한다.

검색 실패, 메타데이터 부재 또는 영상 편집 흔적만으로 허위 영상이라는 결론을 내리지 않는다.

### 6.7 음성·자막·영상 교차검증 모듈

**기능 목적**

음성, 자막, 영상 및 외부 근거의 관계를 검증하여 단일 분석 방식에서 놓칠 수 있는 모순을 탐지한다.

**검증 과정**

1. 음성 발언의 시작·종료 시각을 식별한다.
2. 동일한 시간 구간의 자막과 프레임을 연결한다.
3. 발언과 자막의 주요 개체·숫자·사건을 비교한다.
4. 화면이 해당 주장을 뒷받침하는 영상인지 평가한다.
5. 외부 근거와 모든 분석 결과를 비교한다.
6. 불일치의 유형과 위치를 기록한다.

**교차검증 유형**

| 검사 종류 | 탐지 대상 |
|---|---|
| Audio ↔ Subtitle | 발언과 자막의 내용 불일치 |
| Audio ↔ Evidence | 발언과 실제 근거의 불일치 |
| Subtitle ↔ Evidence | 자막에 표시한 정보와 근거의 불일치 |
| Visual ↔ Evidence | 화면의 출처·시점·장소 불일치 |
| Audio ↔ Visual | 설명한 사건과 화면의 상황 불일치 |

**핵심 원칙**

음성·자막·영상이 모두 같은 내용을 전달해도 반드시 사실인 것은 아니다.

따라서 내부 교차검증 결과와 외부 사실 검증 결과를 반드시 분리하여 기록한다.

## 07. 최종 판정 알고리즘 설계

### 7.1 판정 기준

최종 판단은 LLM의 단일 응답이 아니라 검증된 근거와 사전에 정의한 규칙을 바탕으로 결정한다.

### 7.2 개별 주장 판정

| 상태 | 판단 조건 |
|---|---|
| 근거로 확인됨 | 검증된 직접 근거가 주장을 충분히 지지 |
| 반박됨 | 검증된 직접 근거가 핵심 내용을 명확히 반박 |
| 검증 불충분 | 관련 근거가 없거나 충분하지 않음 |
| 검토 필요 | 신뢰할 만한 증거가 충돌하거나 분석 오류가 의심됨 |
| 검증 대상 제외 | 개인 의견 등 객관적 사실 검증 범위 밖의 주장 |

출처에 접근할 수 없거나 인용문의 존재를 확인하지 못한 근거는 확정 판정에 사용하지 않는다.

### 7.3 영상 콘텐츠 종합 판정

| 종합 상태 | 판정 방식 |
|---|---|
| 주요 주장 확인 | 핵심 사실 주장이 충분한 근거로 확인됨 |
| 일부 사실 | 주요 주장 중 사실과 반박된 내용이 혼재함 |
| 허위 주장 확인 | 핵심 주장이 신뢰할 수 있는 증거로 반박됨 |
| 맥락 왜곡 확인 | 발언 자체와 별개로 영상·자막의 사건 맥락이 명백하게 불일치함 |
| 검증 불충분 | 핵심 주장에 대한 판정이 불가능함 |
| 추가 검토 필요 | 중요한 증거 충돌 또는 분석 오류가 존재함 |

**허위 주장 확인**은 콘텐츠의 모든 내용이 거짓이라는 의미가 아니라, 보고서에 명시된 핵심 주장이 반박되었다는 의미로 제한한다.

### 7.4 종합 판정 조건

초기 PoC에서 적용할 판정 규칙은 다음과 같다.

**규칙 A — 근거 확인**

공식 1차 자료 또는 직접적이고 신뢰할 수 있는 자료가 명확히 주장을 지지하고, 중요한 미해결 모순이 없으면 근거로 확인된 것으로 분류한다.

**규칙 B — 명백한 반박**

검증된 직접 증거가 핵심 주장과 양립할 수 없으면 반박됨으로 분류한다.

**규칙 C — 부분적 오류**

검증된 주장 중 일부는 사실이고 다른 일부는 반박되면 일부 사실로 분류한다.

**규칙 D — 영상 맥락 왜곡**

화면이 다른 날짜·장소·사건에서 사용된 것이라는 직접 증거가 확인되고, 해당 영상이 현재 사건의 장면처럼 제시되었다면 맥락 왜곡으로 분류한다.

**규칙 E — 근거 부족**

검증에 필요한 충분한 자료가 없거나 신뢰 가능한 근거가 서로 충돌하면 확정 판정을 보류한다.

### 7.5 근거 강도 표시

개별 주장에는 판정 결과와 별도로 근거 강도를 표시한다.

- 높음: 직접 근거가 확인되고 핵심 정보가 일치하며 중요한 모순이 해소됨
- 보통: 관련성 높은 근거가 있지만 독립성 또는 직접성에 일부 한계가 있음
- 낮음: 근거가 부족하거나 핵심 정보에 불확실성이 큼

근거 강도는 사실일 확률을 뜻하지 않는다.

초기 시스템에서는 근거 강도를 0~100%의 진실 확률로 표시하지 않는다. 정량적 확률은 향후 평가 데이터로 실제 보정 성능을 확인한 뒤 도입한다.

### 7.6 판정 근거 기록

각 주장마다 다음 정보를 저장한다.

- Claim ID
- 음성·자막 원문
- 분석 시점
- 정규화한 주장
- 관련 프레임 ID
- 근거 URL 및 문서 제목
- 근거 원문과 문서 내 위치
- 발행 기관 및 발행일
- 근거 검증 상태
- 주장과 근거의 의미 관계
- 교차검증 결과
- 최종 판정 및 불확실성
- 판정 규칙 버전과 AI 모델 버전

이를 통해 사용자와 개발자 모두 해당 판정이 만들어진 과정을 추적할 수 있도록 한다.

## 08. 실제 분석 시나리오

### 8.1 가상 뉴스 사례

다음은 시스템 작동을 설명하기 위해 구성한 가상 사례다. 실제 사건이나 공식 통계에 대한 주장이 아니다.

**영상 음성**

"지난해 A시의 인구가 50% 증가했습니다."

**영상 자막**

"A시 인구 증가율 500% 기록"

**영상 화면**

과거 다른 지역의 거리 영상을 현재 A시의 모습처럼 사용한다.

**검증 가능한 가상 자료**

공식 통계에는 해당 기간 A시의 인구 증가율이 5%로 기록되어 있다.

### 8.2 분석 과정

**음성 분석**

- 주장: A시 인구가 50% 증가했다.
- 공식 통계: 5% 증가
- 결과: 반박됨

**자막 분석**

- 자막: 500% 증가
- 음성: 50% 증가
- 공식 통계: 5% 증가
- 결과: 음성과 자막 불일치, 통계와도 불일치

**영상 분석**

- 해당 프레임과 일치하는 과거 다른 지역 영상이 발견됨
- 원본 자료와 게시 맥락을 확인한 경우 다른 사건의 화면이라는 사실 확인
- 결과: 영상 맥락 불일치

### 8.3 사용자 최종 보고서 예시

**종합 판정: 허위 주장 및 영상 맥락 왜곡 확인**

| 항목 | 결과 | 근거 |
|---|---|---|
| 음성 주장 | 반박됨 | 공식 인구 통계와 수치 불일치 |
| 자막 주장 | 반박됨 | 음성 및 공식 통계와 불일치 |
| 영상 화면 | 맥락 왜곡 | 과거 다른 지역 영상과 일치 |
| 근거 검증 | 완료 | 원문·기간·대상 확인 |

**결론**

분석 대상 영상의 주요 수치가 확인된 통계와 일치하지 않으며, 자막과 음성 사이에도 차이가 존재한다. 또한 화면에 사용된 영상 자료가 설명하는 사건과 다른 출처에서 가져온 것으로 확인되었다.

이러한 근거를 바탕으로 해당 콘텐츠에 허위정보 및 맥락 왜곡 요소가 포함된 것으로 판단한다.

사용자는 각 판정 항목에서 실제 근거 URL과 해당 영상 위치를 확인할 수 있다.

## 09. AI Agent 및 AI PoC 설계

### 9.1 AI Agent 적용 목적

본 프로젝트의 AI Agent는 서로 다른 역할을 담당하도록 설계한다.

| Agent | 역할 |
|---|---|
| Claim Agent | 검증 가능한 사실 주장 추출 |
| Retrieval Agent | 외부 근거 자료 검색 |
| Evidence Validator | 원문·출처·날짜·대상 검증 |
| Visual Agent | 자막 및 영상 장면 분석 |
| Cross-Modal Agent | 음성·자막·화면 사이의 불일치 판단 |
| Review Agent | 근거 누락, 과도한 확정 판정 및 모순 확인 |

각 Agent는 미리 정의한 JSON 스키마를 사용하여 결과를 전달한다.

Agent 사이의 의견 일치는 사실성의 증거로 간주하지 않는다. 최종 판정에서는 검증된 외부 근거와 결정 규칙을 우선한다.

### 9.2 AI PoC 검증 목적

AI 기술을 단순히 연결하는 것이 아니라, 실제로 외부 근거 검증과 멀티모달 분석이 필요한지를 실험적으로 확인한다.

### 9.3 비교 실험 구성

동일한 평가 데이터를 대상으로 세 가지 방식을 비교한다.

**실험 A — 기본 LLM 분석**

음성 전사 및 자막 텍스트만 제공하고 LLM이 사실 여부를 판단한다.

**실험 B — 검색 기반 분석**

기본 LLM 분석에 외부 웹 검색을 추가한다.

**실험 C — 제안 시스템**

외부 근거 검색, 원문 검증, 영상 분석, 멀티모달 교차검증, 판정 규칙을 모두 적용한다.

세 실험은 가능한 한 같은 주장 목록과 동일한 평가 데이터를 사용한다.

### 9.4 PoC 평가 데이터셋

**초기 목표:** 90~120개 영상 또는 영상 구간을 수집하고, 주요 사실 주장 단위로 정답과 근거를 별도 주석 처리한다.

데이터 구성 예시:

| 데이터 유형 | 구성 |
|---|---|
| 사실 기반 콘텐츠 | 근거로 검증 가능한 실제 사실 주장 |
| 허위 수치 콘텐츠 | 원래 수치나 날짜를 변형한 사례 |
| 자막 불일치 콘텐츠 | 음성과 다른 수치·기관·날짜를 표시한 사례 |
| 영상 맥락 왜곡 콘텐츠 | 과거 영상이나 다른 사건 영상을 사용한 사례 |
| 근거 부족 콘텐츠 | 확정 판단이 어려운 사례 |

가능하면 공개된 검증 사례와 실험용 변형 콘텐츠를 분리하고, 평가 데이터는 개발 과정에서 사용하는 예시와 중복되지 않도록 구성한다.

실제 영상의 사실 여부와 원본 맥락은 연구자가 직접 확인한 검증 근거를 이용하여 정답을 부여한다.

### 9.5 평가 지표

| 평가 항목 | 측정 기준 |
|---|---|
| Claim Recall | 실제 주요 주장 중 자동 추출된 비율 |
| Evidence Precision@K | 검색 상위 K개 근거의 적합성 |
| Evidence Validity | 인용 원문·URL 검증 성공률 |
| Verdict Macro-F1 | 개별 주장 판정 분류 성능 |
| Cross-modal F1 | 모달 간 불일치 탐지 성능 |
| False Verdict Rate | 잘못된 확정 판정 비율 |
| Abstention Rate | 판단을 유보한 주장 비율 |
| 처리 시간 | 영상 길이 대비 전체 분석 소요 시간 |
| 처리 비용 | 영상 1건당 API 및 인프라 사용 비용 |

검증 불충분으로 분류한 비율과 정답이 존재하는 주장에 대한 판정 성능을 함께 평가해, 무조건 판단을 유보하는 방식이 높은 성능으로 평가되지 않도록 한다.

### 9.6 연구 성공 기준

최종 성공 여부는 단순한 정확도 수치 하나로 결정하지 않는다.

실험 C가 A·B에 비해 주요 성능 지표에서 의미 있는 개선을 보이는지, 특히 출처가 잘못된 인용과 오판정을 감소시키는지 확인한다.

사전에 정의한 평가 지표와 목표치를 실험 시작 전에 고정하고, 실험이 가설을 지지하지 않는 경우에도 실제 결과와 원인을 분석하여 보고한다.

## 12. 차별성 및 독창성

### 12.1 기술적 차별성

**첫째, 영상 정보의 분리·독립 분석**

음성과 영상을 하나의 입력으로만 취급하지 않고 별도 분석 파이프라인으로 처리한다.

**둘째, 시간대별 멀티모달 교차검증**

서로 다른 분석 결과를 동일한 영상 시간에 연결해 구체적인 불일치 위치를 확인한다.

**셋째, 근거 자체의 검증**

AI가 검색한 출처의 존재 여부뿐 아니라 인용문, 기간, 대상, 수치, 출처 독립성까지 확인한다.

**넷째, 근거 기반 판정 및 판정 유보**

불확실한 주장에 대해서는 확정적인 참·거짓 판정을 하지 않는다.

**다섯째, 재현 가능한 검증 기록**

모델 버전, 검색 근거, 검사 결과, 판단 규칙을 기록해 같은 사례를 다시 분석하고 평가할 수 있다.

### 12.2 기존 서비스와의 구분

기존에도 InVID와 같은 영상 프레임 추출 및 역검색 지원 도구가 존재한다.

따라서 본 프로젝트는 영상 팩트체크 자체를 최초로 개발한다는 것을 목표로 하지 않는다.

본 프로젝트의 차별성은 이러한 분석 요소들을 하나의 자동화된 파이프라인으로 연결하고, 독립된 검증 결과를 주장 단위·시간 단위로 통합하며, 실제 평가 데이터로 성능을 검증한다는 점에 있다.

### 12.3 포트폴리오 관점의 기술적 가치

- AI Agent 오케스트레이션

### 15.1 보안 및 개인정보 처리

사용자가 입력하는 영상에는 얼굴, 음성, 개인정보가 포함될 수 있으므로 다음 사항을 적용한다.

- 업로드 파일의 형식·크기 제한
- 파일 분석 작업의 격리
- 임의 URL 요청에 대한 SSRF 방어
- 파일 접근 권한 및 보관 기간 관리
- 사용자 데이터의 불필요한 장기 저장 제한
- 외부 API로 전달하는 데이터 범위 명시

이미지 검색 API를 위해 추출한 프레임을 공개 URL로 제공해야 하는 경우에는 해당 데이터의 공개 가능 여부와 사용자 동의를 별도로 확인한다.

### 15.2 사실 검증의 본질적 한계

본 시스템은 모든 영상의 절대적인 진실을 보증하지 않는다.

근거 자료가 아직 공개되지 않은 사건, 서로 다른 해석이 가능한 주장, 의도적으로 조작된 원자료, 검색으로 찾기 어려운 영상 등은 자동 검증에 한계가 있다.

또한 영상이 실제로 촬영되었음을 확인하는 것과 영상에서 주장하는 내용이 사실임을 확인하는 것은 서로 다른 문제다.

따라서 최종 서비스는 자동 분석 결과와 확인 가능한 근거를 제시하는 의사결정 지원 시스템으로 정의한다.

## 17. 기대 효과

### 17.1 기술적 기대 효과

서로 다른 AI 분석 결과를 근거 중심으로 연결하여 멀티모달 기반 사실 검증 파이프라인을 구현한다.

또한 AI의 추론 결과를 외부 증거와 검증 규칙을 통해 제어함으로써 근거 없는 응답과 과도한 확정 판정을 줄이는 방법을 실험할 수 있다.

### 17.2 사용자 기대 효과

뉴스 영상의 특정 발언과 화면에 문제가 있는지 한눈에 확인하고, 분석 결과를 수동으로 재검토할 수 있도록 지원한다.

이를 통해 사용자가 AI 판정만 신뢰하는 것이 아니라 직접 근거를 확인하고 판단하도록 돕는다.

### 17.3 학술적 기대 효과

외부 검색, 근거 검증, 멀티모달 교차검증이 각각 성능에 미치는 영향을 비교하여 AI 기반 팩트체크 시스템의 가능성과 한계를 정량적으로 분석한다.

## 18. 최종 결론

FactLens AI는 영상의 음성, 자막, 시각적 요소를 독립적으로 분석하고 외부 증거와 대조하여 콘텐츠에 포함된 사실 주장과 맥락 왜곡을 탐지하는 AI 기반 검증 플랫폼이다.

본 프로젝트는 단순히 LLM에게 영상의 진위를 질문하는 구조가 아니다.

각 주장을 원자적으로 분해하고, 근거를 검색하고, 검색한 근거를 다시 확인한 뒤, 음성·영상 간 교차검증 결과를 결합하여 최종 판정을 내리도록 설계한다.

특히 **Evidence Validator와 Cross-Modal Verification Engine**을 중심으로 AI 판단의 신뢰성을 실제 데이터로 검증한다.

궁극적으로 본 프로젝트는 허위정보의 자동 탐지뿐 아니라, **인공지능이 어떤 근거에 의해 판단했으며 그 판단은 어느 정도까지 신뢰할 수 있는가**를 설명하고 검증하는 시스템을 구현하는 데 목적이 있다.
